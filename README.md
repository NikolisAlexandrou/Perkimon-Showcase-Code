# Perkimon — Code Showcase

Perkimon is a 2D monster-taming game developed with Unity and C#, combining exploration, creature collection, and real-time combat.

This repository contains source code from an older development version, shared as a programming portfolio showcase. It does not represent the latest state of the game.

## Project Overview

Perkimon explores systems for managing collectible creatures, controlling their behaviour, and connecting overworld exploration with combat.

## Code Highlights

The source includes work on:

- Real-time monster combat
- Player movement and world interaction
- Monster party management
- Companion following behaviour
- Overworld monster behaviour
- ScriptableObject-based game data structures
- Gameplay UI
- Procedural World Generation (Legacy)

Implementation and feature completeness vary in this archived version.

## Repository Scope

Artwork, audio, creature data assets, and selected project content are intentionally excluded.

The scripts defining data structures may be included, while the corresponding game-specific ScriptableObject assets are omitted.

**This repository is intended for source-code review. It is not a complete, playable Unity project and may contain missing references or dependencies.**

## Technology

- Unity
- C#

## Development Status

Perkimon remains in development. This repository preserves an earlier snapshot, so its architecture, code quality, and gameplay systems may differ from the current project.
